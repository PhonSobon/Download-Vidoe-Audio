      YouTube sign-in

      If YouTube says "Sign in to confirm you're not a bot", upload the cookies of a browser that's logged in to YouTube. They're kept only on this computer.

      How to get cookies.txt: install the Get cookies.txt LOCALLY extension in Chrome/Edge, open a private/Incognito window (allow the extension there), log in at youtube.com, click the extension → Export, then close that window right away (staying in it makes YouTube replace the cookies and the file stops working). If downloads fail again later, export and upload a fresh file.

      Push to Hugging Face

      Each push adds a new Parquet file of your finished MP3s to the dataset (existing files are kept), and adds each source video or page to the References table in its README.

      Get a token with Write permission at huggingface.co/settings/tokens. Leave it blank only if you've run hf auth login or set the HF_TOKEN environment variable.
      Only download content you have the rights to. Up to 3 links download at the same time; the rest wait their turn.
