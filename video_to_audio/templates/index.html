    Format

    YouTube sign-in

    If YouTube says "Sign in to confirm you're not a bot", upload the cookies of a browser that's logged in to YouTube. They stay on this computer.

    How to get cookies.txt
    1. Install the Get cookies.txt LOCALLY extension in Chrome or Edge.
    2. Open a private / Incognito window and allow the extension there.
    3. Log in at youtube.com, click the extension, then Export.
    4. Close that window right away. Staying in it makes YouTube replace the cookies and the file stops working.

    If downloads fail again later, export and upload a fresh file.

    Push to Hugging Face

    Each push adds a new Parquet file of your finished MP3s to the dataset (existing files are kept) and lists each source video in the README's References table.

    Get a token with Write permission at huggingface.co/settings/tokens. Leave it blank only if you've run hf auth login or set the HF_TOKEN environment variable.
